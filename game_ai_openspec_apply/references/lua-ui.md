# Cocos2d-lua 界面制作

先从目标窗口的 Lua 注册、创建函数和相邻资源找到实际 UI 来源，并核对资源搜索路径、图集加载及打包规则。按当前模块维护页面的方式确定主产物。

| 模块做法 | 编辑与交付 |
| --- | --- |
| Lua 代码构建 | 以页面模块（如 `src/app/views/ActivityPanel.lua`）为主产物，复用现有窗口基类、节点创建及布局接口。核对模块返回值、注册名、require 路径及依赖资源，按相邻页面方式挂入窗口管理器。 |
| Cocos Studio 或项目自有布局 | 找到可编辑布局源（如 `.csd`）和本模块实际使用的导出方式。在源文件中维护节点，用项目匹配的导出器生成运行时布局（如 `.csb`），核对 Lua 加载路径、子节点名或 tag 以及适用的动画轨道。契约记录源与导出物的映射。只有二进制时，先定位对应源或受支持的编辑链。 |

从父节点坐标、锚点、可见区域和项目适配策略换算设计位置。将按钮、列表、文字与图集帧映射到项目已有的控件或构建函数；用实际资源搜索顺序检查同名文件遮蔽和大小写。对需先加载的图集，核对纹理、描述文件和帧名是否一并进入目标包。

用客户端自己的窗口工厂或场景入口加载交付物，验证触摸回调、滚动/裁剪、关闭重开，以及监听、定时器和动作的退出清理。分别记录源修改、导出、真入口加载和截图比对结果。缺少导出器时保留可编辑源与待导出事项；缺少客户端时可做已有的静态检查，运行和视觉验收保持待执行。
